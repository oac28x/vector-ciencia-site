Privacy Policy — Vector Ciencia Studio

Last updated: November 24, 2026

1. Data Collected

Vector Ciencia Studio is a single-creator private desktop/server tool. It does not collect, sell, rent, or process personal data from public users or third parties.

2. OAuth Tokens & Permissions

When the owner authorizes an official Vector Ciencia account (such as TikTok via Login Kit and Content Posting API), OAuth access and refresh tokens are stored locally in an encrypted/private local directory on the owner's machine solely to upload and publish original educational videos.

3. Data Sharing

No user data or authentication credentials are shared with any third party. API requests are sent directly to official platform APIs (TikTok, Google/YouTube, Meta/Facebook/Instagram).

4. Data Deletion & Revocation

The owner may revoke application access at any time from TikTok, Google, or Meta account security settings and delete local token files immediately.
